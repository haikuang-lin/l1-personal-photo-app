隱私與使用限制

本工具不含帳號、分析追蹤、雲端上傳、伺服器端 API 或照片持久快取。替換照片或清除工作階段會釋放照片像素、座標、雜湊與報告的 App 參照；模型資源可保留於記憶體供下次使用。瀏覽器與作業系統的底層記憶體無法保證安全抹除。偵測可能漏掉側臉、過小或被遮擋的人臉，請在公開前人工檢查。
